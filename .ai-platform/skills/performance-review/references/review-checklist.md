# performance-review Review Checklist

## 입력 확인

- 성능 목표
- 트래픽/데이터 규모
- 측정 결과
- 코드/쿼리
- 인프라 제약

## 리뷰 절차

1. 목표 지표를 먼저 확정한다.
2. 추측보다 측정 지점을 제시한다.
3. DB/API/캐시/렌더링 병목을 분리한다.
4. 개선 전후 검증 방법을 쓴다.

## 판정 기준

- 측정 없이 최적화하지 않는다.
- 캐시 무효화 리스크를 기록한다.
- 복잡도 증가 비용을 평가한다.

## 결과 형식

- Summary: 변경/검토 대상 한 줄 요약
- Must Fix: 병합/배포 전 필수 수정
- Should Improve: 품질 개선 권장 사항
- Evidence: 근거 파일, 테스트, 로그, 측정값
- Verification: 수정 후 다시 실행할 명령
