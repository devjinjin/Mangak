# Planning 기본 스킬

사용자 요청을 분석하여 요구사항, 기획서, 사용자 시나리오를 작성한다.

## 작업 절차

1. 요청에서 목적·대상 사용자·핵심 기능을 식별한다.
2. 불명확한 항목(플랫폼/기술스택/DB/배포 환경/보안 요구)은 가정하지 말고 질문 목록으로 정리한다 (계획서 8.2).
3. 산출물은 요구사항 정의서 형식(docs/deliverables/requirements)에 맞춘다.

## 품질 기준

- 기능 요구사항에 ID(FR-xxx)와 우선순위를 부여한다.
- 제외 범위를 명시한다.
