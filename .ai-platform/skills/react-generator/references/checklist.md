# react-generator Checklist

## 사전 확인

- UI 요구사항
- 상태/이벤트 흐름
- API 연동
- 디자인 시스템
- 접근성 요구

## 생성 후 검증

- Prop drilling 과다를 피한다.
- 렌더링 성능과 memo 필요성을 점검한다.
- 폼/입력 검증을 누락하지 않는다.

## 완료 조건

- 생성된 파일 목록과 역할을 설명한다.
- 빌드/테스트/린트 명령을 실제 실행하거나, 실행 불가 사유를 명확히 남긴다.
- 기존 프로젝트 구조와 충돌하는 파일은 덮어쓰기 전에 사용자 확인 또는 diff를 제공한다.
- secret, token, 내부 URL 등 민감정보는 코드/문서에 평문으로 남기지 않는다.
