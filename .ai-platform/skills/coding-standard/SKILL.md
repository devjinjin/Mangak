# coding-standard

프로젝트별 코딩 표준과 언어별 관례를 적용해 일관된 코드를 유지한다.

## 입력

- 대상 언어/프레임워크
- 기존 코드 스타일
- 회사 표준 문서
- 변경 범위

## 산출물

- 적용 표준 요약
- 위반/수정 목록
- 리팩토링 제안
- 검증 명령

## 작업 절차

1. 기존 코드에서 우선 규칙을 추출한다.
2. 네이밍, 모듈 경계, 예외, 로깅 규칙을 확인한다.
3. 자동 포맷/린트 명령을 제시한다.

## 품질 기준

- 표준을 새로 invent하지 않는다.
- 기능 변경과 스타일 변경을 섞지 않는다.
- 예외 사유를 기록한다.

## 사용 원칙

- 내부 개발 도구용 스킬이다. 외부 공개나 public marketplace 배포를 전제로 하지 않는다.
- 프로젝트의 기존 구조, 회사 표준, 보안 정책, Definition of Ready/Done을 우선한다.
- 모호한 입력은 가정하지 말고 필요한 확인 질문과 누락 문맥을 먼저 정리한다.
