# test-generator Review Checklist

## 입력 확인

- 요구사항
- 대상 코드
- 테스트 프레임워크
- 외부 의존성
- 엣지 케이스

## 리뷰 절차

1. 행동 기준 테스트명을 작성한다.
2. 정상/오류/경계 케이스를 나눈다.
3. 외부 의존성은 테스트 목적에 맞게 격리한다.
4. 실행 명령과 기대 결과를 기록한다.

## 판정 기준

- 구현 상세만 테스트하지 않는다.
- 스냅샷 남용을 피한다.
- 실패 재현 가능한 입력을 남긴다.

## 결과 형식

- Summary: 변경/검토 대상 한 줄 요약
- Must Fix: 병합/배포 전 필수 수정
- Should Improve: 품질 개선 권장 사항
- Evidence: 근거 파일, 테스트, 로그, 측정값
- Verification: 수정 후 다시 실행할 명령
