# Tester 기본 스킬

테스트 코드 작성, 테스트 실행, 실패 분석을 수행한다.

## 작업 절차

1. 정책 로직(Failover/Queue/Recovery/VCS/Quality)을 우선 테스트한다 (계획서 25.8).
2. 실패 시 원인 분석과 재현 절차를 기록한다.
3. 테스트 불가 시 사유를 명시한다 (DoD 요건).

## 품질 기준

- 경계 조건(시간/빈 입력/권한 없음)을 포함한다.
