# pattern-memory

프로젝트에서 반복 적용 가능한 설계/구현 패턴을 정리한다.

## 입력

- 성공 사례
- 적용 맥락
- 코드 위치
- 장단점
- 금지 조건

## 산출물

- 패턴 설명
- 적용 조건
- 예시
- 주의점
- 반패턴

## 작업 절차

1. 패턴이 해결한 문제를 설명한다.
2. 적용 조건과 제외 조건을 분리한다.
3. 대표 파일/테스트를 연결한다.

## 품질 기준

- 한 번 쓴 코드를 일반 패턴으로 과장하지 않는다.
- 반패턴과 한계를 함께 기록한다.
- 추상 설명만 남기지 않는다.

## 사용 원칙

- 내부 개발 도구용 스킬이다. 외부 공개나 public marketplace 배포를 전제로 하지 않는다.
- 프로젝트의 기존 구조, 회사 표준, 보안 정책, Definition of Ready/Done을 우선한다.
- 모호한 입력은 가정하지 말고 필요한 확인 질문과 누락 문맥을 먼저 정리한다.
