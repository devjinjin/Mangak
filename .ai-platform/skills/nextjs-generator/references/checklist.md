# nextjs-generator Checklist

## 사전 확인

- 페이지 요구사항
- 라우팅 구조
- 데이터 소스
- 인증 방식
- SEO/성능 요구

## 생성 후 검증

- 불필요한 use client를 피한다.
- 민감정보가 클라이언트 번들에 노출되지 않게 한다.
- 라우트별 성능 영향을 설명한다.

## 완료 조건

- 생성된 파일 목록과 역할을 설명한다.
- 빌드/테스트/린트 명령을 실제 실행하거나, 실행 불가 사유를 명확히 남긴다.
- 기존 프로젝트 구조와 충돌하는 파일은 덮어쓰기 전에 사용자 확인 또는 diff를 제공한다.
- secret, token, 내부 URL 등 민감정보는 코드/문서에 평문으로 남기지 않는다.
