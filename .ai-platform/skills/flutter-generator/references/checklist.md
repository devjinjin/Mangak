# flutter-generator Checklist

## 사전 확인

- 화면 요구사항
- 상태관리 방식
- API 명세
- 플랫폼 권한
- 디자인 가이드

## 생성 후 검증

- BuildContext 오남용을 피한다.
- 민감정보를 평문 저장하지 않는다.
- 반응형/접근성 요구를 반영한다.

## 완료 조건

- 생성된 파일 목록과 역할을 설명한다.
- 빌드/테스트/린트 명령을 실제 실행하거나, 실행 불가 사유를 명확히 남긴다.
- 기존 프로젝트 구조와 충돌하는 파일은 덮어쓰기 전에 사용자 확인 또는 diff를 제공한다.
- secret, token, 내부 URL 등 민감정보는 코드/문서에 평문으로 남기지 않는다.
