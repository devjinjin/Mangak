# idc-deploy

IDC 환경에서 서버, 네트워크, 프로세스, 로그, 백업을 고려해 배포한다.

## 입력

- 서버 정보
- 네트워크/방화벽
- 런타임
- 배포 계정
- 백업/롤백 요구

## 산출물

- 배포 절차서
- 서비스 등록
- Nginx/프록시 설정
- 로그/백업
- 롤백 절차

## 작업 절차

1. 서버 접근/계정/권한을 확인한다.
2. 포트와 방화벽을 점검한다.
3. 서비스 관리 방식(systemd 등)을 정한다.
4. 백업과 롤백을 먼저 준비한다.

## 품질 기준

- 수동 변경만 남기지 않는다.
- 운영 secret을 문서에 쓰지 않는다.
- 재시작/롤백 명령을 검증한다.

## 사용 원칙

- 내부 개발 도구용 스킬이다. 외부 공개나 public marketplace 배포를 전제로 하지 않는다.
- 프로젝트의 기존 구조, 회사 표준, 보안 정책, Definition of Ready/Done을 우선한다.
- 모호한 입력은 가정하지 말고 필요한 확인 질문과 누락 문맥을 먼저 정리한다.
