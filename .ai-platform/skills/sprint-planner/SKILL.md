# sprint-planner

백로그를 스프린트 목표, 용량, 리스크에 맞춰 계획한다.

## 입력

- 백로그
- 팀 용량
- 우선순위
- 휴가/일정
- 릴리즈 목표

## 산출물

- 스프린트 목표
- 선정 작업
- 용량 배분
- 리스크/버퍼
- 데모 기준

## 작업 절차

1. 스프린트 목표를 먼저 정한다.
2. 필수/선택 작업을 나눈다.
3. 리스크와 버퍼를 표시한다.
4. 데모 가능한 결과물을 정의한다.

## 품질 기준

- 용량을 초과하지 않는다.
- 의존성 높은 작업을 숨기지 않는다.
- 완료 기준 없는 항목을 넣지 않는다.

## 사용 원칙

- 내부 개발 도구용 스킬이다. 외부 공개나 public marketplace 배포를 전제로 하지 않는다.
- 프로젝트의 기존 구조, 회사 표준, 보안 정책, Definition of Ready/Done을 우선한다.
- 모호한 입력은 가정하지 말고 필요한 확인 질문과 누락 문맥을 먼저 정리한다.
