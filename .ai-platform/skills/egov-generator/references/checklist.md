# egov-generator Checklist

## 사전 확인

- 업무 기능명
- 메뉴/권한 정보
- 테이블 또는 VO 정의
- 검색/페이징 조건
- 전자정부 버전/템플릿

## 생성 후 검증

- 전자정부 표준 명명 규칙을 따른다.
- SQL 인젝션 위험을 제거한다.
- 공통 컴포넌트 중복 구현을 피한다.

## 완료 조건

- 생성된 파일 목록과 역할을 설명한다.
- 빌드/테스트/린트 명령을 실제 실행하거나, 실행 불가 사유를 명확히 남긴다.
- 기존 프로젝트 구조와 충돌하는 파일은 덮어쓰기 전에 사용자 확인 또는 diff를 제공한다.
- secret, token, 내부 URL 등 민감정보는 코드/문서에 평문으로 남기지 않는다.
