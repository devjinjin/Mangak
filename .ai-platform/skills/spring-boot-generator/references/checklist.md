# spring-boot-generator Checklist

## 사전 확인

- 기능 요구사항
- 도메인/엔티티 후보
- API 경로와 메서드
- 인증/권한 요구사항
- DB/트랜잭션 제약

## 생성 후 검증

- 계층 의존 방향을 위반하지 않는다.
- 설정값을 하드코딩하지 않는다.
- 입력 검증과 예외 응답을 포함한다.

## 완료 조건

- 생성된 파일 목록과 역할을 설명한다.
- 빌드/테스트/린트 명령을 실제 실행하거나, 실행 불가 사유를 명확히 남긴다.
- 기존 프로젝트 구조와 충돌하는 파일은 덮어쓰기 전에 사용자 확인 또는 diff를 제공한다.
- secret, token, 내부 URL 등 민감정보는 코드/문서에 평문으로 남기지 않는다.
