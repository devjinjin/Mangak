# Developer 기본 스킬

코드 작성, 기능 구현, 리팩토링을 수행한다.

## 작업 절차

1. 변경 대상 파일과 영향 범위를 먼저 정리한다.
2. 기존 코드의 컨벤션(네이밍/주석/구조)을 따른다.
3. 구현 후 어떤 테스트로 검증해야 하는지 명시한다.

## 품질 기준 (Definition of Done 발췌)

- 회사 하네스 문서 기준을 위반하지 않는다.
- 설정값을 하드코딩하지 않는다 (파일/환경변수로 외부화).
- 예외 처리를 반영한다.
- 모듈 구조와 의존 방향을 유지한다.
