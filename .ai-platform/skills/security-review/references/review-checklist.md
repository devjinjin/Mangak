# security-review Review Checklist

## 입력 확인

- diff
- 위협 모델
- 인증/권한 구조
- 데이터 민감도
- 외부 연동

## 리뷰 절차

1. 공격 표면을 식별한다.
2. 권한 우회와 입력 검증을 점검한다.
3. secret/로그/오류 메시지를 확인한다.
4. 의존성 취약점과 설정 노출을 본다.

## 판정 기준

- 추정만으로 취약점이라고 단정하지 않는다.
- 위험도를 분류한다.
- 조치 후 검증 방법을 제시한다.

## 결과 형식

- Summary: 변경/검토 대상 한 줄 요약
- Must Fix: 병합/배포 전 필수 수정
- Should Improve: 품질 개선 권장 사항
- Evidence: 근거 파일, 테스트, 로그, 측정값
- Verification: 수정 후 다시 실행할 명령
