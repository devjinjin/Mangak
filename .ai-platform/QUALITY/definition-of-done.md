# Definition of Done (계획서 18.5)

- [ ] 요구사항이 구현되었다.
- [ ] 하네스 문서 기준을 위반하지 않았다.
- [ ] 관련 코드가 모듈 구조를 유지한다.
- [ ] 예외 처리가 반영되었다.
- [ ] 설정값이 하드코딩되지 않았다.
- [ ] 테스트를 실행했거나 실행 불가 사유를 기록했다.
- [ ] 리뷰 결과가 기록되었다.
- [ ] 보안 검토가 필요한 경우 수행했다.
- [ ] Checkpoint가 생성되었다.
- [ ] Commit 메시지가 규칙에 맞다.
- [ ] 다음 작업 또는 남은 이슈가 기록되었다.
